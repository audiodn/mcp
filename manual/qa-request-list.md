# Fresh MCP request list (written before consulting the tool registry)

Jobs a person would actually ask an AI agent connected to AudioDN:

1. I just connected — who am I / what’s my org?
2. Upload this audio file for me (no collection mentioned).
3. Make a private playable link for a track.
4. Set this up like a podcast episode (presets / formats).
5. Transcribe this and give me captions.
6. Give me an embeddable player snippet.
7. What’s my plan, subscription, and AI credit balance?
8. Make my audio louder / normalize to LUFS.
9. Is this track done processing / can I play it yet?
10. Find the track (or collection) named X.
11. Revoke an API key / set up URL signing.
12. Odd: create an upload with no file bytes and no collection.
13. Odd: wait for playback before any bytes are uploaded.
14. Odd: delete a track, but only as a dry run.
15. Before signing in: build a player embed from docs alone.
